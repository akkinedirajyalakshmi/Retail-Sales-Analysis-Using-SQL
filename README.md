# Retail Sales Analysis Using SQL

## Project Overview

This project analyzes retail sales data using SQL to uncover customer purchasing behavior, product performance, and revenue trends.

The project was developed to strengthen practical SQL skills by solving real-world business problems using relational databases.

## Database Structure

### Customers
- Customer ID
- Customer Name
- City
- Country

### Products
- Product ID
- Product Name
- Category
- Price

### Orders
- Order ID
- Customer ID
- Product ID
- Order Date
- Quantity

## SQL Concepts Applied

### Basic Queries
- SELECT
- WHERE
- Aggregate Functions

### Joins
- Inner Join

### Aggregations
- COUNT()
- SUM()
- AVG()
- MAX()

### Grouping
- GROUP BY
- HAVING

### Advanced SQL
- Subqueries
- Correlated Subqueries
- CASE Statements

### Window Functions
- RANK()
- DENSE_RANK()
- LEAD()
- LAG()

## Business Problems Solved

- Calculate total revenue
- Find top customers by spending
- Identify highest revenue-generating products
- Analyze category-wise sales
- Rank customers based on spending
- Find products contributing the most revenue
- Customer segmentation using CASE statements
- Revenue percentage contribution analysis

## Key Insights

- Electronics generated the highest revenue.
- Customer spending varied significantly across regions.
- A small number of customers contributed a large share of total revenue.
- Window functions helped identify top-performing customers and products.

## Skills Demonstrated

SQL Server, Data Analysis, Data Cleaning, Joins, Aggregations, Subqueries, Window Functions, Business Intelligence.
